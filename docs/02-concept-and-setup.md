# 컨셉 확정과 초기 세팅 목록

작성일: 2026-10-20

## 확정된 컨셉

- 주제: 옷 컬러 조합 추천 (체형 보완 아님)
- 인물: 얼굴과 신원이 드러나지 않는 실루엣/마네킹 형태. 레퍼런스는 @hairmensguide(팔로워 약 200만, 게시물 2,568개)의 게시물로, 얼굴 없는 흰 마네킹에 헤어스타일만 입혀 1~6번으로 보여주고 "Which is your style?"이라고 묻는 캐러셀이다.
- 적용: 같은 마네킹 인물이 매일 다른 컬러 조합 코디를 입고, 번호를 붙인 여러 장으로 보여준 뒤 "몇 번이 좋아요?"라고 묻는다.
- 장점: 얼굴 일관성 문제가 없고, 시선이 옷 색에만 간다. 번호 투표형 질문이 댓글을 만든다.

## 1. 사람이 먼저 정할 것

| 항목 | 선택지 |
|---|---|
| 타깃 | 남성 / 여성 / 둘 다 (계정을 나누거나 요일별로 번갈아 게시) |
| 언어 | 한국어 / 영어 (영어면 해외 노출이 넓어짐) |
| 형식 | 캐러셀 이미지 / 릴스 / 캐러셀 위주에 가끔 릴스 |
| 인물 표현 | 흰 마네킹 / 검은 실루엣 / 얼굴 없는 3D 인형 |
| 한 게시물 구성 | 예: 표지 1장 + 조합 4~6장 + 색상 칩 정리 1장 |
| 수익화 | 당장은 없음 / 나중에 제휴 링크 / 처음부터 제휴 링크 |

## 2. 브랜드 기준 문서

- 마네킹 기준: 체형, 포즈 3~4종, 피부 재질, 카메라 각도, 크롭 범위
- 배경과 조명: 색, 그림자, 바닥
- 레이아웃: 번호 위치, 색상 칩(HEX와 색 이름) 위치, 폰트, 여백
- 캡션 틀, 질문 문구, 해시태그 세트
- 금지 사항

## 3. 계정과 API

- 인스타그램 새 계정 → 프로페셔널(크리에이터 또는 비즈니스) 계정으로 전환, 2단계 인증
- Meta 개발자 앱 생성 → Instagram API(Instagram 로그인 방식) 연결 → 게시 권한 → 장기 액세스 토큰 발급과 자동 갱신
- 게시용 이미지를 올릴 공개 URL 저장소 (Cloudflare R2, AWS S3, Cloudinary 등). 인스타그램 API는 파일을 직접 받지 않고 공개 URL에서 가져간다.

## 4. 생성 도구

- 이미지 생성 API 키
- 마네킹 기준 이미지 세트를 먼저 만들고, 같은 인물로 보이는지 10~20장 시험 생성
- 번호, 색상 칩, 글자는 이미지 모델에 그리게 하지 않고 코드로 합성 (글자 오류와 색 오차 방지)
- 색 검수: 생성된 옷 영역의 색을 뽑아 목표 HEX와 비교, 차이가 크면 재생성

## 5. 데이터 소스

- 색 조합 DB: 색 이름, HEX, 조합 규칙(보색, 유사색, 톤온톤 등), 계절 태그. 초기 200~300개 조합을 미리 만들어 둔다.
- 네이버 개발자센터 앱 등록 → 데이터랩 API (국내 색상·코디 검색어 추이)
- 공공데이터포털 → 기상청 단기예보 API (기온에 맞는 옷 두께와 계절감)
- 트렌드 컬러 수동 입력표: Pantone 올해의 색, 시즌 컬러 발표 등

## 6. 운영 기반

- 게시 이력 DB: 날짜, 사용한 색 조합, 이미지 URL, 캡션, 성과 지표 (처음에는 SQLite나 Google Sheets로 충분)
- 매일 정해진 시간에 실행하는 스케줄러: 노트북은 꺼지거나 잠들 수 있으므로 클라우드 실행(GitHub Actions, 작은 서버 등) 권장
- 게시 전 승인 채널: 처음 2~4주는 텔레그램 등으로 미리보기를 받고 승인하면 게시
- 비밀 키 보관: .env 파일, 저장소에 커밋 금지

## 나중에 붙일 것

- 댓글 수집과 "몇 번" 투표 집계 → 인기 조합을 다음 주제에 반영
- 성과 수집 (게시 후 24시간, 7일)
- 제휴 링크: 같은 색 상품 검색(쿠팡 파트너스, 네이버 쇼핑 API)과 댓글→DM 자동 발송
